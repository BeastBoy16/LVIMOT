# LVIMOT Windows v1.0.0

Platform release for Windows with the validated CARLA 0.9.13 / Python 3.8 environment.

Includes the live LVIMOT dashboard, RGB-LiDAR-IMU pipeline, MOT, local 4-D map, evaluation path, tests and Windows setup/launch scripts.

CARLA, datasets, virtual environments and generated outputs are not bundled.
