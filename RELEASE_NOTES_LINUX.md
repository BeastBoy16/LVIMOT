# LVIMOT Linux v1.0.0

Platform release for Ubuntu/Linux with CARLA 0.9.16 / Python 3.12.

Includes the live LVIMOT dashboard, RGB-LiDAR-IMU pipeline, MOT, local 4-D map, evaluation path, tests and Linux setup/launch scripts. The live ego RGB view resizes to fill its dashboard panel.

CARLA, datasets, virtual environments and generated outputs are not bundled.
